First time? Create your token
  1. Open GitHub’s fine-grained token settings.
  2. Select only thchrischoi.github.io.
  3. Set repository Contents permission to Read and write, choose an expiration, then generate the token.
  4. Save it in your password manager and paste it here. Never add it to a post or repository.
